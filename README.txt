# Cosmetic Store — GitHub Pages

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` التصميم
- `script.js` زر واتساب والبحث
- `images/` جميع صور المنتجات المرفوعة

## قبل النشر
افتح `script.js` وغيّر:
`const WHATSAPP_NUMBER = "01203341917";`
إلى رقم واتساب المتجر بصيغة دولية بدون + أو مسافات.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. سمّه مثلاً `cosmetic-store`.
3. ارفع **محتويات** هذا المجلد، وليس مجلد `cosmetics_github_site` نفسه.
4. من Settings → Pages.
5. تحت Build and deployment اختر `Deploy from a branch`.
6. اختر Branch: `main` و Folder: `/ (root)`.
7. اضغط Save.
8. بعد دقائق سيظهر رابط الموقع في صفحة Pages، ويكون بالشكل:
`https://USERNAME.github.io/cosmetic-store/`
